# RZXXY Proxy Tester

A lightweight Python tool for testing internet
connectivity and HTTP proxy configuration.

## Features

- Check internet connectivity
- Display public IP information
- Check HTTP response status
- Enable or disable proxy configuration
- Read proxy settings from environment variables

## Requirements

- Python 3.9+
- requests

## Installation

git clone https://github.com/Ryzxxy8/RZXXY-Proxy-Tester.git

cd RZXXY-Proxy-Tester

python3 -m pip install requests

## Usage

python3 src/proxy_checker.py

## Testing

python3 -m unittest discover -s tests -v

## Security

Never commit proxy credentials or .env files.
